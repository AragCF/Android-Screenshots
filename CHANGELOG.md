# Изменения

## 1.1.5 — 2026-10-05

- Исправлен повторяющийся stale framebuffer на Jetinno JL22 / UniWin_M190 (Android 6).
- Подтверждено на реальном устройстве: `screencap` по USB и сети, а также через временный файл на Android, возвращал один и тот же старый аварийный кадр SHA-256 `0bafc525...`.
- Для этого известного stale-кадра добавлен точечный резервный путь: односекундный `screenrecord` + извлечение первого кадра через FFmpeg. На той же JL22 видеотракт возвращает актуальный логический экран 1280x800.
- Обычные устройства по-прежнему используют быстрый `adb exec-out screencap -p`; резервный видеопуть включается только при точном совпадении известного stale SHA-256.
- На Windows добавлена обработка Alt+F4 / закрытия консольного окна через `CTRL_CLOSE_EVENT`; меню перестало навечно блокироваться на `getwch()`, а запись видео получает шанс штатно завершиться.


## 1.1.4 — 2026-10-01

- Релизный GitHub Actions синхронизирован с текущей архитектурой видео: DEB теперь содержит `Recommends: scrcpy`, а описание пакета отражает запись видео через scrcpy.

- Сохранён прежний быстрый путь снимка через `adb exec-out screencap -p`.
- Если vendor ADB возвращает перед PNG посторонний текст, программа находит реальную PNG-сигнатуру в начале потока и отбрасывает только служебный префикс.
- Если `exec-out` вообще не возвращает корректный PNG, включается резервный путь: `screencap` сохраняет PNG на Android, затем файл забирается через `adb pull`.
- Резервный путь пробует `/data/local/tmp` и `/sdcard`, после чего удаляет временный файл.
- При полном отказе обоих способов сообщение об ошибке содержит диагностические первые байты ответа ADB.
- Устройства, где прежний путь работал, проходят по нему без дополнительных действий.
- `update.bat` теперь автоматически добавляет точный каталог проекта в Git `safe.directory`, устраняя ошибку `detected dubious ownership` на Studio.
- Windows-сборщик и обновлятор теперь находят Python не только как `python`, но также через `py -3` и машинный Miniconda Python (`C:\\ProgramData\\miniconda3\\python.exe`), что позволяет собирать проект из-под службы GitHub Runner.


## 1.1.3 — 2026-09-27

- Полностью убрана блокирующая проверка ориентации/геометрии снимка на Android 6.
- Восстановлен проверенный путь захвата: adb exec-out screencap -p.
- Исправление видео 1.1.1 сохранено без отката.
- Проблема ложного framebuffer при параллельной ADB-нагрузке пока не маскируется эвристикой; для неё будет отдельная диагностическая работа.


## 1.1.2 — 2026-09-27

- Для Android 6 и старше добавлена проверка геометрии снимка относительно текущей ориентации SurfaceFlinger.
- Исправлен случай UniWin_M190, когда при параллельной ADB-нагрузке screencap мог возвращать старый portrait framebuffer 800x1280 вместо текущего landscape 1280x800.
- Некорректный legacy-снимок больше не сохраняется: программа повторяет захват, чередуя exec-out и временный файл на Android.
- При длительном конфликте с другим ADB-сеансом программа выдаёт явную ошибку вместо сохранения ложного кадра.
- Современные Android используют прежний быстрый путь без дополнительных проверок.


## 1.1.1 — 2026-09-26

- Видеодвижок переведён с самодельной цепочки screenrecord → FFmpeg на scrcpy.
- Устранено накопление тысяч кадров в очереди FFmpeg и тяжёлое послезавершение записи.
- Исправлена ориентация записи: scrcpy фиксирует текущую ориентацию Android при старте.
- Настройка FPS теперь задаёт верхний предел захвата через scrcpy --max-fps.
- Во время записи используется временный MKV; после остановки он быстро перепаковывается без повторного кодирования в MP4 с faststart.
- Новые незавершённые .recording.mkv восстанавливаются при следующем запуске.
- Старые .recording.mp4 от видеодвижка 1.1.0 переносятся в Videos/Legacy_1.1.0 и больше не восстанавливаются повторно.
- Для Android 11+ микрофон использует scrcpy --audio-source=mic; на старых Android остаётся запасной путь через tinycap.


## 1.1.0 — 2026-09-26

- При выборе устройства курсор устанавливается на уже выбранное устройство.
- Последнее устройство сохраняется в пользовательских настройках и восстанавливается при следующем запуске, если доступно.
- Для последнего сетевого устройства выполняется безопасная попытка повторного adb connect.
- Добавлена запись видео в каталог Videos; каталог исключён из Git.
- Добавлены настройки итогового FPS: 6, 12, 24, 30, 45 и 60.
- Видео записывается как fragmented MP4 и при штатной остановке перепаковывается в обычный MP4 с faststart.
- Добавлено автоматическое восстановление незавершённых .recording.mp4.
- Добавлен опциональный захват микрофона Android через tinycap на совместимых прошивках; по умолчанию звук выключен.
- FFmpeg используется как отдельная системная зависимость; на Windows программа пытается установить Gyan.FFmpeg через WinGet.
- Добавлены штатные update.bat и update.sh.
