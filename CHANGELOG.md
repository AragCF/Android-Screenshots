# Изменения

## 1.1.0 — 2026-09-26

- При выборе устройства курсор устанавливается на уже выбранное устройство.
- Последнее устройство сохраняется в пользовательских настройках и восстанавливается при следующем запуске, если доступно.
- Для последнего сетевого устройства выполняется безопасная попытка повторного adb connect.
- Добавлена запись видео в каталог Videos; каталог исключён из Git.
- Добавлены настройки итогового FPS: 6, 12, 24, 30, 45 и 60.
- Видео записывается как fragmented MP4 и при штатной остановке перепаковывается в обычный MP4 с faststart.
- Добавлено автоматическое восстановление незавершённых .recording.mp4.
- Добавлен опциональный захват микрофона Android через tinycap на совместимых прошивках; по умолчанию звук выключен.
- FFmpeg используется как отдельная системная зависимость; на Windows программа пытается установить Gyan.FFmpeg через WinGet.
- Добавлены штатные update.bat и update.sh.


## 1.0.2 — 2026-09-24

- Добавлены параметры `--version` и `-V`, работающие без запуска ADB.
- Добавлена автоматическая сборка Windows EXE и Debian DEB через GitHub Actions.
- Добавлен чистый ZIP исходников через `git archive`.
- Добавлено формирование `SHA256SUMS.txt` и автоматическая публикация GitHub Release.

## 1.0.1 - 2026-09-23

- Снимки сохраняются в каталог Screenshots.
- Screenshots исключён из Git как каталог с потенциально чувствительными данными.
- Главное меню сохраняет выбранную строку после возврата; повторный снимок можно запускать Enter.

## 1.0.0 — 2026-09-23

- Первая версия.
- Выбор ADB-устройства стрелками, Enter и цифрами.
- Поддержка USB и уже подключённых сетевых ADB-устройств.
- PNG и JPG, качество JPG 99.
- Имя снимка содержит модель устройства, дату и время.
- Сохранение в текущую рабочую папку.
- Автоматическая установка Pillow при запуске исходника, если выбран JPG.
- Автоматизированная сборка EXE и DEB.
