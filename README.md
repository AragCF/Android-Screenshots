# Android Screenshot Tool 1.0.1

Консольная утилита для Windows и Linux, которая делает снимки экрана Android через `adb`.

## Возможности

- единый список USB- и сетевых устройств из `adb devices -l`;
- выбор устройства стрелками `↑/↓`, `Enter` или цифрами;
- выбранное устройство постоянно видно в главном меню;
- главное меню сохраняет ранее выбранную строку, поэтому повторный снимок можно делать одним Enter;
- если устройство ещё не выбрано, команда снимка сначала открывает выбор устройства;
- PNG без перекодирования;
- JPG с качеством 99, без цветовой субдискретизации (`subsampling=0`);
- имя файла: `Модель_YYYY-MM-DD_HH-MM-SS.png|jpg`;
- снимки сохраняются в подкаталог Screenshots текущей рабочей папки;
- каталог Screenshots исключён из Git и не попадает в публичный репозиторий;
- перед снимком состояние выбранного устройства проверяется повторно;
- `offline` и `unauthorized` показываются в списке, но не выбираются как рабочие;
- при запуске исходного `.py` Pillow для JPG устанавливается автоматически, если отсутствует;
- EXE и DEB собираются как автономные бинарники с Pillow внутри.

## Требования

- `adb` заранее установлен и доступен в `PATH`;
- для запуска исходного файла: Python 3;
- для сетевого Android устройство должно уже быть подключено командой `adb connect IP:PORT` (либо иным штатным способом ADB), после чего оно появится в том же меню, что и USB-устройства.

## Запуск исходника

Windows:

```bat
python android_screenshot_tool.py
```

или двойным щелчком по `run_windows.bat`.

Linux:

```bash
python3 android_screenshot_tool.py
```

или:

```bash
./run_linux.sh
```

## Главное меню

1. Сменить устройство.
2. Сделать снимок экрана.
3. Формат снимка: PNG/JPG.
0. Выйти.

## Сборка EXE на Windows

Запустить:

```bat
build_exe.bat
```

Сценарий сам:

1. создаёт `.venv-build-win`;
2. обновляет `pip`;
3. устанавливает Pillow и PyInstaller;
4. собирает `dist\AndroidScreenshotTool.exe`.

## Сборка DEB на Debian/Ubuntu

Запустить:

```bash
chmod +x build_deb.sh
./build_deb.sh
```

Сценарий сам устанавливает недостающие системные средства сборки через `apt-get` (с `sudo`, если он доступен), создаёт `.venv-build-linux`, загружает Pillow и PyInstaller, собирает автономный Linux-бинарник и затем `.deb` в каталоге `dist/`.

Установка готового пакета:

```bash
sudo apt install ./dist/android-screenshot-tool_1.0.1_*.deb
```

После установки запуск:

```bash
android-screenshot-tool
```

## Ограничения

- Утилита не включает Android Platform Tools внутрь EXE/DEB и не меняет настройки ADB: по условию задачи `adb` уже должен быть доступен в `PATH`.
- `build_exe.bat` нужно запускать именно в Windows: PyInstaller собирает исполняемый файл для текущей ОС.
- `build_deb.sh` собирает пакет для архитектуры Linux-машины, на которой он запущен.
